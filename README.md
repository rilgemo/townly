# Townly

A small idle RPG about growing a town through exploration.

## Status

Early prototype

## Tech Stack

- TypeScript
- Phaser
- Vite

## Vision

Start from a tiny town.

Explore the four surrounding regions.

Discover resources.

Upgrade the town.

Unlock new adventures.

## Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
